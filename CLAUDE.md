# Правила работы в репозитории

## Проект и лицензия
- Проект открытый, лицензия GNU AGPL-3.0. Новый код идёт под ней же. Зависимости с несовместимой лицензией не добавляем.
- Название PlugBackup и логотип в AGPL не входят, см. `TRADEMARKS.md`.

## Секреты
- Никаких секретов в коде и коммитах: ни паролей, ни токенов, ни ключей, ни реальных адресов.
- Настройки и секреты берём только из `.env`. В репозитории лежит `.env.example` с заглушками.
- Примеры конфигов в `node/` пишем с заглушками. Для адресов используем зарезервированные для документации диапазоны (`192.0.2.0/24`, `2001:db8::/32`).

## Подписи ИИ
- Никаких подписей ИИ. Не пишем `Co-Authored-By`, «Generated with», ссылки на сессии и упоминания ИИ в коммитах, PR, файлах и комментариях.

## Коммиты
- Conventional Commits на английском: `feat:`, `fix:`, `docs:`, `chore:`.
- Сообщения короткие и по делу.
- Перед коммитом запускаем `pre-commit run --all-files`.

## Шрифты
- Только шрифты с открытой лицензией (OFL).
- Лицензия кладётся рядом с файлами шрифтов.
