# design/

Дизайн-система PlugBackup: токены, шрифты, логотип, компоненты, анимации и графика для Telegram и сайта. Принципы бренда и тон голоса: [brand.md](brand.md).

Название PlugBackup и логотип не входят в лицензию AGPL, см. [TRADEMARKS.md](../TRADEMARKS.md). Код этой папки распространяется по AGPL-3.0, шрифты по SIL OFL 1.1 (тексты лицензий лежат в [fonts/](fonts)).

## Как открыть витрину

Откройте файл [index.html](index.html) в браузере, например двойным щелчком. Сервер и сборка не нужны: на странице нет внешних запросов, шрифты и картинки лежат рядом. Переключатель в шапке меняет тему, «Авто» следует за настройкой системы.

Если хочется открыть по адресу, подойдёт любой статический сервер:

```bash
cd design
python -m http.server 4173
```

После этого страница доступна на `http://127.0.0.1:4173/`.

## Как перегенерировать картинки

Нужен Node.js 20 или новее. Зависимости ставятся один раз:

```bash
cd design
npm install
```

После правок в шаблонах графики или в текстах:

```bash
npm run export
```

Команда читает `graphics/src/*.svg`, подставляет тексты из `data/` и цвета из `tokens.json`, сохраняет SVG в `graphics/svg/` и PNG в `graphics/png/`. PNG рисует [resvg](https://github.com/RazrFalcon/resvg), шрифты берутся из пакетов IBM Plex, системные шрифты не нужны.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run build` | Собирает всё: `tokens.css`, `contrast.md`, логотип, графику (SVG и PNG), генерируемые блоки в `index.html` |
| `npm run export` | Только графика: SVG и PNG |
| `npm run check` | Проверяет, что контрасты проходят AA, а `tokens.css` и `contrast.md` совпадают с `tokens.json`. Код возврата ненулевой, если нет |
| `npm run fonts` | Заново копирует шрифты из `node_modules` в `fonts/` (нужно только при смене версии Plex) |

## Что где лежит

| Путь | Что это |
| --- | --- |
| `index.html` | Витрина: токены, компоненты, анимации, графика |
| `tokens.json` | Источник правды для цветов, шрифтов, отступов, радиусов, теней, длительностей и кривых |
| `tokens.css` | CSS-переменные, **создаётся из `tokens.json`**. Светлая и тёмная темы: `prefers-color-scheme` и атрибут `data-theme="light"` или `"dark"` на `<html>` |
| `contrast.md` | Таблица контрастов WCAG AA, создаётся из `tokens.json` |
| `components.css` | Компоненты: кнопки, карточки тарифов, блок кода, плашки, предупреждения, поля |
| `animations.css` | Анимации: появление логотипа, индикатор загрузки, hover. Уважает `prefers-reduced-motion` |
| `showcase.css`, `showcase.js` | Вёрстка и скрипты самой витрины, в сайт их брать не нужно |
| `fonts/` | IBM Plex Sans и Mono (woff2), `fonts.css` и лицензии. См. [fonts/README.md](fonts/README.md) |
| `logo/` | Логотип в SVG: знак, слово, горизонтальная версия, варианты для светлого, тёмного и одного цвета. **Создаётся скриптом**, вручную не правьте |
| `graphics/src/` | Шаблоны графики: аватар, описание бота, баннеры, Open Graph, favicon, apple-touch-icon |
| `graphics/svg/`, `graphics/png/` | Готовые SVG и PNG, создаются командой `npm run export` |
| `data/plans.json` | Тарифы: объёмы, цены, пометки. Единственное место, где они записаны |
| `data/graphics.json` | Тексты на картинках |
| `scripts/` | Сборка. `build.mjs` запускает остальные шаги |

## Как что менять

**Цену или объём тарифа.** Правьте только `data/plans.json` и запустите `npm run build`: обновятся карточки на витрине, баннер «Тариф» и примеры текстов на баннерах. Ссылка на бота и пометка про бету тоже лежат в этом файле.

**Текст на баннере.** Правьте `data/graphics.json` и запустите `npm run export`. Перенос строки пишется как `\n`. В значениях можно ссылаться на тарифы: `{{plans.gb50.price}}`, `{{plans.beta.size}}`. Если строка длиннее, чем помещается, скрипт напишет предупреждение. Тексты в файле сейчас примеры, замените их своими.

**Баннеры для бота.** Бот берёт из `graphics/png` три картинки: `banner-announce` (приветствие), `banner-update` (тарифы) и `banner-paid` (после оплаты, без цифр). Первые два собраны из `data/plans.json`: после смены объёмов или цен пересоберите их командой `npm run export`.

**Баннер «Тариф» для другого плана.** В `data/graphics.json` у `banner-plan` поменяйте `plan` на `beta`, `gb50`, `gb100` или `gb200`.

**Макет картинки.** Правьте `graphics/src/*.svg` в любом SVG-редакторе или руками. Подстановки выглядят как `{{title}}`; `{{@mark:on-dark}}` и `{{@lockup:on-dark}}` вставляют знак и логотип. Описание синтаксиса: начало файла `scripts/lib/template.mjs`.

**Цвета, шрифты, отступы.** Правьте `tokens.json` и запустите `npm run build`. Если контраст какой-то пары упал ниже AA, сборка остановится и назовёт пару.

**Логотип.** Геометрия знака и слова описана в `scripts/lib/pins.mjs`. После правок `npm run build` обновит и `logo/`, и графику.

## Зависимости

Все нужны только для сборки, в браузере ничего из них не запускается.

| Пакет | Для чего | Лицензия |
| --- | --- | --- |
| `@resvg/resvg-js` | SVG в PNG | MPL-2.0 |
| `opentype.js` | Контуры букв для слова в логотипе | MIT |
| `@ibm/plex-sans`, `@ibm/plex-mono` | Источник шрифтов | OFL-1.1 |
