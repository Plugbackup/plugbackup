# Логотип

Эти файлы создаёт скрипт `scripts/build-logo.mjs` (команда `npm run build` в каталоге `design/`), вручную их не правьте. Правила использования: [brand.md](../brand.md).

Название PlugBackup и логотип не входят в лицензию AGPL: права на них остаются за автором проекта. Форкам и чужим сервисам использовать их нельзя, см. [TRADEMARKS.md](../../TRADEMARKS.md).

| Файл | Что это |
| --- | --- |
| `logo-*.svg` | Знак и слово в одну строку |
| `mark-*.svg` | Только знак |
| `wordmark-*.svg` | Только слово |
| `mark-circle-*.svg` | Знак в круге, для аватаров |
| `*-on-light.svg` | Для светлых фонов |
| `*-on-dark.svg` | Для тёмных фонов |
| `*-mono-black.svg`, `*-mono-white.svg` | Один цвет |

Слово нарисовано контурами, шрифты для показа файлов не нужны.
