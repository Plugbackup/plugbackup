# Шрифты

В дизайн-системе используются два шрифта с открытой лицензией:

- **IBM Plex Sans** (400, 500, 600) для текста и интерфейса;
- **IBM Plex Mono** (400, 500, 600) для кода, цифр тарифов и подписей.

Оба под [SIL Open Font License 1.1](OFL-IBM-Plex-Sans.txt). Авторские права: © 2017 IBM Corp., зарезервированное имя шрифта «Plex». Тексты лицензий лежат здесь же: `OFL-IBM-Plex-Sans.txt` и `OFL-IBM-Plex-Mono.txt`.

## Откуда файлы

Файлы `.woff2` взяты без изменений из npm-пакетов `@ibm/plex-sans` 1.1.0 и `@ibm/plex-mono` 2.5.0 (каталог `fonts/split/woff2`). Это официальные нарезки IBM по диапазонам символов, поэтому шрифт не модифицирован и имя Plex остаётся законным.

| Нарезка | Что внутри |
| --- | --- |
| `Cyrillic` | Кириллица |
| `Latin1` | Основная латиница, кавычки, тире, многоточие, € |
| `Latin2` | Расширенная латиница и валюты, в том числе ₽ |
| `Pi` | Номер «№», стрелки, математические знаки, ✓, узкий неразрывный пробел |

`fonts.css` подключает файлы через `unicode-range`: браузер скачивает только те нарезки, символы которых есть на странице. Греческую нарезку и `Latin3` (вьетнамский) не берём.

Заново скопировать файлы и пересоздать `fonts.css` можно командой `npm run fonts` в каталоге `design/`.

## Размещение на своём сервере

Шрифты загружаются только с вашего домена, сторонние CDN не нужны. Положите каталог `fonts/` рядом с сайтом и подключите:

```html
<link rel="stylesheet" href="/fonts/fonts.css">
```

Пути внутри `fonts.css` относительные, поэтому каталог можно переносить целиком. Для кэширования отдавайте `.woff2` с долгим `Cache-Control`.
