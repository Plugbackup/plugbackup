# PlugBackup

Хранилище для резервных копий для VPN- и privacy-комьюнити. Копии отправляются по SFTP через restic или rclone и шифруются на вашей стороне до отправки. Оплата и выдача доступа идут через Telegram-бота.

> Проект в бете, его делает один человек. Этот документ описывает замысел и будет уточняться по мере появления кода.

- Сайт: [plugbackup.site](https://plugbackup.site)
- Бот: [@PlugBackupBot](https://t.me/PlugBackupBot)

## Как это работает

1. В боте [@PlugBackupBot](https://t.me/PlugBackupBot) вы оплачиваете хранилище и получаете доступ.
2. Бот выдаёт данные для SFTP-подключения к ноде хранения.
3. Вы настраиваете restic или rclone у себя. Они шифруют данные до отправки.
4. Нода принимает уже зашифрованные данные по SFTP. Клиенты изолированы друг от друга (chroot), а место ограничено ZFS-квотой.

```
 Ваше устройство                       Нода хранения
┌──────────────────┐   SFTP   ┌────────────────────────────────┐
│ restic / rclone  │ ───────► │ sshd: chroot на каждого клиента │
│ шифрование здесь │          │ ZFS: квота на клиента           │
└──────────────────┘          └────────────────────────────────┘
                                              ▲
                          ┌───────────────────┘
                 Telegram-бот: оплата и выдача доступа
```

## Модель безопасности

**Шифруется на вашей стороне.** Ключ и пароль шифрования остаются у вас, на ноду они не передаются.

- restic шифрует данные репозитория и его метаданные, в том числе имена файлов и структуру каталогов.
- rclone шифрует содержимое файлов. Имена файлов и каталогов он шифрует, если в настройках включено шифрование имён (`crypt`).

**Что видит владелец сервиса.**

- Не видит содержимое резервных копий и ваш пароль шифрования. Имена файлов он тоже не видит, если шифрование имён настроено по инструкции.
- Видит, сколько места вы занимаете и какая у вас квота.
- Видит количество и размеры зашифрованных объектов и время их изменения.
- Видит сетевые метаданные SFTP-соединения, например IP-адрес, с которого вы подключаетесь. PlugBackup не скрывает ваш адрес от ноды. Если это важно, подключайтесь через свой VPN.
- Бот знает, к какому Telegram-аккаунту привязан доступ и оплачен ли он.

**Если вы потеряете пароль шифрования, восстановить данные будет нельзя.** У нас его нет.

Об уязвимостях сообщайте по [SECURITY.md](SECURITY.md).
